# 交付前设计审核

审核对象：本包的实验任务、配置、数学分解、数据边界、选择与发布流程。未访问用户GPU、未训练控制器、未运行新数据或新地图；下列“通过”均指设计级核对。

|检查项|结论与处理|
|---|---|
|前缀解释|按coverage银行前缀，不当作时序在线扫描；必须报告实际n和别名。|
|基线保留|FC/文本/两份FG2权重不变；surface-bias M1不再扩展。|
|反事实减法|Compose必须使用U-new_base，不能直接接另一分支的旧delta。|
|三层证据|事实/推导/待检验机制明确分开，没有把视图退化直接解释为噪声。|
|无未来信息|先截到当前prefix；动作和所有统计仅用当前集合。|
|同位置合同|同对象条件内site固定；四条件不交叉复用；不只改views列表。|
|标签隔离|GT只生成TRAIN utility或离线评分，前向24标量无类别/身份；GT-best不是方法。|
|原开放词汇边界|controller target使用base160；最终竞争全200；系统不是training-free。|
|强对照|静态base/残差、同模型耦合动作、同容量无新增对应统计均有定义。|
|训练公平|两臂同初始化/draws/目标/步数；无新增FG2或骨干梯度；两种子最多8000更新。|
|训练触发|仅TRAIN，原件去重计数；未通过不降阈值，静态对照仍继续。|
|选择锁|57个逻辑候选上限；seed17锁step/tau/C_STAR；seed29不再选。|
|性能结论|主目标8前缀改善，4前缀非明显退化；不强迫准确率逐视图单调。|
|计算账|动作oracle全部枚举、phi/搬运/局部head均计时；小MLP≠总计算很小。|
|调用上限|预地图原head最多82920理论格，配置85000；全局重组不重做phi。|
|地图协议|原G1 owner/原rank/NQF保持；最多208新逻辑行；父硬编码调度不直接复用。|
|发布|普通新branch C1/C2；C1收据在C2；C2终态在OUT，不自引用未来SHA。|
|测试与范围|只6组必要测试，不增全仓/全盘/多GPU审计；未授权新RGB/SAM/几何。|

## 仍需要执行时确认

1. 父缓存、对象数组、mask面积与实际环境是否齐全。
2. 真实FP32 Compose对角是否与原head相同；数学等价不替代实际数值核对。
3. TRAIN动作空间能否达到学习支持规则；未测，不能承诺会触发训练。
4. 控制器是否能泛化到DEV/真实图提案；既有GT派生输入和4个DEV家族限制仍在。
5. 边际utility回归能否胜强简单对照；满足内部资源门槛不等于显著或可投。

附带reference_branch_compose.py只检验代数与动作构造的小规模合成性质，不是FG2完整实现。运行结果在reference_selftest.json。不能将其写成真实接入验证通过。
