## 一、从已核实代码到实验干预

| 已有事实 | 判断 | 实际任务 |
|---|---|---|
| v2空mask已经使用面积权重；正常路径保持原pooling | 不应再把面积pooling作为新颖性 | 保留B1，增加真正不同的细粒度重采样 |
| classify_regions有向量就argmax；build_method_outputs把可用直接转成输出 | 只校准概率不一定影响最终AP | 显式区分feature_available、proposed_class与accepted |
| construct_output允许恢复label子集，重新计算官方排名 | 无需改几何就可以测试接受/暂缓 | 使用低层导出接口，禁止伪造旧available字段 |
| runtime_parity已经实现R2精确加速 | 无需回退慢版搜索 | 识别视图和mask保持不变，额外几何只在已选帧计算 |
| AnyUp的平均注意力用于加权未投影的稠密V | 有明确的可修改接口 | 在注意力后、V加权前加入owner/depth软权重 |
| FC稠密特征与文本空间并不同维 | 不能对类别概率或最终向量上采样 | AnyUp处理clip_vis_dense，随后过原冻结视觉头 |

这些关系的源文件与具体引用见 `SOURCE_EVIDENCE.md`。

## 二、九种固定配置（两个继承基线、七个新条件）

| 配置 | 作用 | 关键比较 |
|---|---|---|
| EV00_D2 | 不恢复的强基线 | CF18目标必须超过它的AP |
| EV01_G1_V2 | 当前完整方法 | Replica五项均不得低于它才算目标达成 |
| EV02_MARGIN | 简单类别间隔门控 | 防止复杂验证只相当于调阈值 |
| EV03_CONTRAST | 几何混合度调制的目标—竞争区域语义对照，随后门控 | 对比EV02判断竞争证据是否有用 |
| EV04_BILINEAR | 同输出分辨率、同pool/head的普通插值 | 防止把增益全归给AnyUp模型 |
| EV05_ANYUP | 原版冻结AnyUp | 检验简单接模型是否已经足够 |
| EV06_OWNER_ANYUP | AnyUp注意力加入owner/depth软约束 | 对比EV05检验几何的额外价值 |
| EV07_COMBINATION | EV06表示＋EV03决策 | 检验表示和接受机制是否互补 |
| EV08_NO_DEPTH | EV06去掉深度因子 | 区分owner与depth的作用 |

全部用同一低支持/混合支持触发集合：原粗特征正支持格少于4，或面积占据纯度低于0.5。
非触发对象精确保留B1；原有D2实例在全部条件中完全不变。
这些数值是本轮固定试验设定，不是已证实的最优参数。

## 三、两个拟议机制是什么

### 竞争区域语义对照

仅在原G1帧中，用完整预测几何和测量深度找目标附近、归属于其他正owner的区域。
最多两个，未知区域不作反证。同类邻居可能存在，所以这些是竞争解释而不是GT负样本。
目标cosine减去按混合度调制的竞争区域类别响应，然后用固定0.01的top1-top2间隔接受/暂缓。
没有合法对照时不构造虚假负证据，只退化到同样的简单间隔规则。

这不是贝叶斯后验、因果证明或复杂图推理。它是可解释的待验证算法，必须胜过简单门控。

### 归属/深度约束重采样

先取得AnyUp原始平均头注意力，再用当前目标的低分辨率owner占据比例、未知支持和
目标内的测量深度一致性重加权，重新归一化后聚合原始FC稠密值。
未知深度中性、未知owner不视为错误对象、全部系数保留正下界；普通窗口mask不变。
将几何因子全部置1必须复现普通AnyUp。新方法不是把网格ID做双线性插值，也不是
在已经混合完的最终向量上贴一个“几何”权重。

## 四、工作阶段与限额

| 阶段 | 必做内容 | 限额/边界 |
|---|---|---|
| 绑定 | 当前v2、R2、实际候选/视图/模型/评价身份 | 不重跑旧大审计，不伪装旧任务ID |
| 基线诊断 | 现有恢复的几何不足、类别错误、FP/重复、跨场景评分 | 只读已有预测；最多每benchmark一个排名反事实诊断 |
| 真接口试测 | office1、scene0011_00 | 只验张量、padding、普通AnyUp及中性分支，不选参 |
| 共享证据 | 原G1帧；一次FC编码；AnyUp共享Q/K与注意力块 | 不增加视图、最多两个竞争区域 |
| 固定矩阵 | 两benchmark，九配置 | 234条scene-method记录、18个完整池化；52基线可继承 |
| 研究选模 | 同一个配置满足CF18改善、Replica五项不降 | 属于已曝光数据上的探索性推荐，不是独立确认 |
| 完整增量计时 | 最多四个有解释力的方法、八场景两次 | 上限64次；新AnyUp不允许记作零成本 |
| 发布 | 实际代码、分数、决定、诊断、成本和交接 | 正常push并核验完整SHA；部署不自动替换 |

最多使用已有26张几何，新增建图数为0。每场景候选不超过原有128，不截断已冻结候选。
234条结果不是234次建图，也不是234次不同模型前向。相同视图/特征在科学采集中共享，
但冷测不得拿旧投影或特征抵扣方法成本。完整计算数量按实际请求报告。

## 五、目标如何判定

必须相对于**当前完整A3 v2**保护Replica全部五项指标，而不是只保护较弱的D2。
CF18全部五项至少不低于A3 v2，APall须超过D2，AP50至少达到D2。
CF18 APall超过D2 0.10个百分点以上另标为实质幅度目标；这不是统计显著性。
仅有数值浮点容差，不用0.1个百分点“容忍”冒充完全不降。

如果简单门控、双线性或原版AnyUp获胜，就保留简单方法，并降低复杂机制的新颖性主张。
若无人通过，保留B1和完整取舍表，不按数据集切换方法，不追加看结果挑场景或阈值。
所有场景此前已曝光，任何选出的研究冠军都不能改称未见泛化验证。
