# 中文源码审核与任务拆解

## 1. 本轮要验证什么

不是继续放大LR08，而是分开验证三个命题：

| 命题 | 上轮证据 | 本轮处理 |
|---|---|---|
| 学习式二维读出至少不弱于原FC | H上FC8为33.66% Top-1，学习MA和提名模型均为23.27% | 先做残差起点×教师保持的四个匹配对照 |
| 三维对应有独立作用 | SURFACE较VIEW有局部正信号，但依附于受损MA基础 | 两个种子都取得合格二维基础后，冻结基础再比较分组 |
| 归属监督真正减少污染贡献 | 同一表面内的softmax会抵消组内共同升降 | 分开“观测质量”和“目标归属”，把归属用于组级路由并加入保持通道 |

上述数值和接口依据见SOURCE_EVIDENCE；本包没有产生新的服务器实验结果。基线代码锁定6767eb90c2fd6999621b356b87269c012821713a。

## 2. 这次审核修正了什么

**第一，不用已经退化的MA预热作为共同起点。** 四种二维模型重新使用相同随机初始化和相同训练样本，均训练2,000步，不继承旧的2,000步预热。旧LR05只作历史参照，不能冒充本轮匹配控制。

**第二，零残差与可学习性兼顾。** 使用`FC + 当前MA - 冻结初始MA`，而不是“零输出层再乘零门控”。初始功能等于同输入FC，第一步仍可向MA传梯度。冻结初始MA需要保存并计入推理依赖，不能隐瞒它的计算成本。

**第三，保持FC不等于保持G1。** 同视图FC8的读出与历史F不同。初始化检查以FC8为参照；整图晋级仍以当前D2+G1为参照。两者不混用。

**第四，目标归属不再被组内归一化吞掉。** 质量Q决定同一组内不同视图的相对权重；归属M预测整组是不是目标。所有几何对照都有同一个null通道，只有G4/G5将M输出用于路由，因此G4对G3检验的是直接使用归属，而不是多一层网络。

**第五，修正组数混杂。** VIEW最多8组、SURFACE最多64组；路由对局部证据总量除以有效组数J，避免SURFACE仅因组数更多就挤走null。均匀分数下，各种组数的总局部权重都为0.5。

**第六，不在路由后的修正向量上重新归一化。** 修正后接无偏置线性层；否则所有组都不可靠时，小修正可能被再次放大。只在加回基础表示后执行最终L2归一化。该性质不保证AP单调提高。

**第七，选模先看识别，不再只看基础类别CE。** DEV仍仅使用基础类对象的标签，但让预测与完整200类竞争，优先Top-1、宏平均召回和干净对象保持，CE只作后续排序。

## 3. 固定实验

### 二维四臂

| 编号 | 方法 | 目的 |
|---|---|---|
| R0 | 直接MA，共同分类/一致性损失 | 匹配控制 |
| R1 | FC功能残差，相同损失 | 初始能力保留作用 |
| R2 | 直接MA，加有条件教师保持 | 损失约束作用 |
| R3 | 残差+教师保持 | 二者是否互补 |

教师正确性仅由TRAIN干净对象的普通FC与TRAIN标签决定；教师错时不强迫学生复制。推理时不存在这个GT判断分支。

|---|---|---|---|---|
| G1 | 按视图 | 无 | 无 | 无 |
| G2 | 按物理表面 | 无 | 无 | 无 |
| G3 | 按物理表面 | 有 | 无 | 无 |
| G4 | 按物理表面 | 有 | 有 | 无 |
| G5 | 按物理表面 | 有 | 有 | 有 |

五臂输入、参数形状、初始局部分支和样本顺序一致。二维基础全程冻结。两个种子均重复五臂，不能只重复最复杂版本，却宣称SURFACE–VIEW也已复现。

## 4. 数据与监督

原24个TRAIN家族和4个DEV家族不改变，保持622个基础正样本对象的实际清单。新方法不训练在CF18/Replica，也不借旧H选模。旧H已曝光，只作回归。

新H2从官方TRAIN中排除原32家族、CF18和已知历史使用家族，按固定哈希锁定4个新家族。在所有模型和种子提名冻结前，不解析其语义标注或生成GT派生样本。H2仍是新家族proposal识别，不是新的独立整图AP。

额外用既有SAM2在4个DEV家族各2帧上生成真实预测mask，最多8图、128个保留proposal。无GT点框；先锁定候选和输入，再用GT做诊断匹配。它只检查合成proposal到实际预测proposal的迁移，不进入训练或选模，也不替换OVI前端。

## 7. 工程与发布

目标分支`research/ovimap-preservation-routing-v1`。新入口、绑定、训练和方法注册独立实现，旧分支硬编码断言保持。严格复用实际FP32特征、phi、文本、输出分区、官方排名及池化。

发布真实代码、配置、小型学习权重及其冻结初始参照/基础依赖、训练组件曲线、每次DEV检查、紧凑指标和四份报告；不上传原始受限数据或基础模型权重。正常push后核验完整SHA，外部回执记录PUSH_VERIFIED。

只做12组有针对性的数值/梯度/接口检查与2对象20步工程试验，不重跑全仓或堆上千项验收。参考测试不是生产模型，不代表GPU训练已经通过。实际服务器执行与数据可用性仍须由Codex核验。
