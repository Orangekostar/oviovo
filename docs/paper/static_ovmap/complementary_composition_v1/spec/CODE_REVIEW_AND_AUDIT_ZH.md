## 1. 本次任务为什么不再照搬上一轮组合入口

旧研究发现了 Q_GAIN 和 SigLIP2 的平均正向信号，但没有任何模块通过其逐场景保留门槛，所以旧组合没有真正运行。旧组合入口还会先对最终区域重新执行原生语义读出，不能代表“保留 Q 的已有判断，再引入第二来源”。因此，本轮需要一个独立、规模有限的组合研究，而不是修改旧结果来放行。依据：SRC02–04。

| 旧 SELECT 场景 | N0 uAP / mIoU（%） | Q_GAIN | SigLIP2 AREA |
|---|---:|---:|---:|
| scene0445_00 | 42.2222 / 51.7056 | 38.8889 / 50.9068 | 38.8889 / 47.0171 |
| scene0626_00 | 9.2593 / 18.9633 | 25.1684 / 36.3359 | 16.0774 / 25.8290 |

这两路在场景层面的涨跌同向，不能从均分推导对象互补已经成立。必须看同一个原生实例上谁改对、谁改错；也不能根据上述表格写“0445用N0、0626用Q_GAIN”的路由。数值是旧研究的描述性证据，不是本轮选模数据或性能承诺。

## 2. 源码事实 → 风险 → 最终处理

| 已确认的事实 | 不处理会造成什么问题 | 最终指令对应 |
|---|---|---|
| `query_study.replay_captured()` 在每帧查询前根据已付费原生特征评分 | 直接换成SigLIP2会同时改变后续查询，无法解释是识别变好还是查询改变 | M3/M4先冻结完整原生尝试轨迹，再用独立SigLIP2状态强制重读；不反馈控制器。SRC05、08–10 |
| `CurrentLineage` 会依据完整当前片段关系转移证据，并永久丢弃不明确/已逐出的特征 | 仅根据最终owner和最后top10重建，会把早期已丢弃的证据错误复活 | 逐帧回放相同谱系和所有尝试；原生同模型回放先验证与原结果相同。SRC06 |
| Q保留最多10个观测；N0使用原生末8个观测；静态S2使用最多3个请求，当前AREA已修复为保留原始六裁剪均值幅度 | 统一成一个看似干净的读出会改变旧对照，掩盖组合来源 | 三种源控制保持原口径；不再重复旧归一化修复；不把静态S2三视图直接替代轨迹S2。SRC07、11、14–15 |
| 静态语义预测失败会回退N0 | 回退结果会形成虚假的“两个模型一致” | M1/M2显式读取`technical_fallback`和有效视图；回退不占票、不占混合权重。SRC11 |
| 当前`native_combine_candidates()`会先更新覆盖再判可见面积 | 把它当纯过滤器、每个候选反复调用，会改变策略 | M5每帧只调用一次，包括零配额帧；不顺便修正原生行为。SRC07 |
| `FeatureStore`在一个store内部以request为缓存键 | 两个模型共用store，可能把native特征当SigLIP2特征 | 两个模型分别建store和模型身份空间，跨目录导入须证明输入完全一致。SRC07、09 |
| repaired `rgb_siglip` 显式指定 HWC；旧基类没有该显式声明 | 窄crop可能再次产生通道歧义，污染整个模型对照 | 所有新增图像编码用已修复backend，不进行环境重建。SRC13 |
| N0 mask来自已核对的原生网格绘制，排名已序列化冻结 | 替换成原始体素owner或G_ORIGINAL会让语义实验混入几何变化 | 所有方法保持同一N0坐标、owner和数值排名，仅输出新类别向量。SRC14、17 |
| 旧确认入口要求旧研究保留候选，并限制旧方法集合 | 直接调用会再次全部阻断；伪造旧锁又会破坏研究记录 | 新增独立组合确认契约，明确授权两个原始场景和固定方法；不改旧门槛、不伪装角色。SRC18–20 |
| 数据路径和权重根目录已存在于发布配置 | 把记录的路径当作已读取数据，或换成Hub最新权重，造成身份漂移 | Codex先按实际回执绑定；复用已经测量的snapshot与Q checkpoint，不重新选epoch。SRC21–22 |

**最终审核修正：**再次读取498版本的`semantic_selector.area_readout()`后确认，它已经修复了旧版本的逐视图再归一化问题。最终英文指令和源码表已同步更新，不能再按fde版本的旧问题安排重复修复。

这些发现限定了接入方式，不证明某个新组合一定有效。

## 3. 实验矩阵与各自意义

| 条件 | 完整含义 | 固定项 | 真正检验 |
|---|---|---|---|
| M1 | Q_GAIN和静态S2有真实证据且同类才替换N0 | 几何、排名、供体集合 | 跨来源一致性是否减少有害覆盖 |
| M2_RAW | 三路完整类别分布、固定温度0.07、等权 | 同上 | 不训练复杂路由的软证据融合 |
| M2_CAL | 与M2_RAW相同，仅使用各来源独立温度 | 同上、同可用性 | 校准是否提供额外作用，还是简单融合已经足够 |
| M3 | 原生Q_COMBINE全部尝试轨迹→SigLIP2重读 | 轨迹、区域、谱系、几何、排名 | 原生覆盖轨迹上替换识别器的效果 |
| M4 | 原生Q_GAIN全部尝试轨迹→SigLIP2重读 | 同上 | 收益查询与新识别器是否出现协同 |
| M5 | 一个B200预算、一个native历史，覆盖/收益按尝试槽交替优先 | 同编码器、预算、几何、排名 | 能否平衡覆盖与查询收益，降低场景波动 |
| M6 | M5固定轨迹→SigLIP2重读 | 与M5同轨迹 | 只在CAL已支持两种构件时检验进一步组合 |

五个机制对应六个必做配置，因为M2包含一个廉价、必要的未校准对照。先在2个CAL和2个已见回归场景生成24条新组合记录；M6触发后增加4条。现有四种源控制另列，可按完整身份复用。相同预测并不要求重新评测，但每个条件必须有独立的来源和决策记录。

M3/M4组成2×2矩阵：原生COMBINE/GAIN轨迹 × native/SigLIP2读出。相减能区分轨迹、识别器和交互，不需要重新建图。M1/M2不是严格B200方法；M3/M4也要付原生控制轨迹加SigLIP2重读的双路代价。

## 4. 校准、选模和确认规则

### 4.1 校准不占用旧SELECT或新确认集

本轮不训练Q或语义小头，只拟合三个来源的标量温度。两个旧CAL场景采用留一场交叉拟合：评估某场时，温度由另一场拟合。拟合目标是明确几何对应对象上的场景平衡NLL，不是AP；样本不足时固定回退T=0.07，明确标记未校准，不伪造数据。

所有来源保持自身的分数定义：N0原生canonical-relative值，Q最终余弦，S2原有AREA余弦。不混合两个图像特征空间，也不把映射分数称为概率正确性保证。温度标定参考EXT01，但阈值、默认值和样本门槛是本轮工程选择。

### 4.2 允许探索组合，不改写上一轮科学结论

新组合无需先通过旧的单模块保留门槛。M6只看CAL上的已规定平均弱支配规则；REGRESSION结果不能触发M6或调整比例。CAL按uAP、mIoU、逻辑成本、固定顺序提名一个有真实干预的组合，同时锁定最佳单分支。

候选即使CAL存在取舍，也可开展一次预先指定的确认。这是新协议明确授权的验证，不等于自动部署，不等于上一轮保留门槛已通过。旧的N0/NO_NET_GAIN保持原样。

### 4.3 防止“新盲测”仍是旧场景

- `scene0056_00 / scene0534_00`：COMPOSE_CAL，历史上已用于校准，不称新的盲测。
- `scene0445_00 / scene0626_00`：只在冻结后做回归，不能按其表现换方法。
- `scene0553_00 / scene0064_00`：确认；先检查是否仍未被用于选择，再按新契约导出原始数据。
- 旧FIT八场景只提供现有Q模型及历史证据，不重新训练或推理一遍。

确认最多一个组合加四个预先指定控制；只有M6被提名时额外评估M5，总共最多6种输出/场景。仍只涉及2场，不称总体泛化证明。

## 6. 成本与实施边界

| 项目 | 限制与解释 |
|---|---|

| 新训练 | 无大模型/小头训练；仅极小的标量温度拟合 |
| CAL/回归建图 | 不重跑，复用native-v10 |

| 静态S2 | 仍最多128目标×3请求，但所有最终实例都参与评测 |
| 语义失败 | M1/M2不把回退当票；轨迹重读无有效证据时按原Q口径输出0，不能偷偷保留N0来抬分 |
| 共享缓存 | 可以减少物理前向，不能抹掉方法逻辑成本；必须按真实模型和区域身份复用 |
| 测试 | 只针对本轮接口/数值/隔离风险；一次真实同模型回放验证并复用其产物 |
| 发布 | 只交付新代码与新结果；不重搬旧16,430个文件，不做反复全量发布扫描 |

M5的50/50是槽位偏好；如果COMBINE没有候选会让给GAIN，实际比例必须报告。M3/M4是固定原生控制器的双阶段诊断，不是已经完成“SigLIP2直接驱动在线Q”的系统。
