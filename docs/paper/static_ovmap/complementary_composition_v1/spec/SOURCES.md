## External primary sources

- **EXT01 — Guo et al., On Calibration of Modern Neural Networks, ICML 2017.** https://proceedings.mlr.press/v70/guo17a.html . Supports single-temperature scaling as a calibration method. It does not establish calibration or generalization for our three sources, nor justify any threshold or scene count in this protocol.
- **EXT02 — Google SigLIP2-L/16-384 model card.** https://huggingface.co/google/siglip2-large-patch16-384 . Confirms the model identity and image/text feature interfaces. This task reuses the previously measured immutable local snapshot, not whatever is latest on the Hub.

All mixing ratios, default temperatures, finite calibration bounds, support floors, experiment gates and budgets in the new protocol are predeclared engineering choices. They are not represented as optimal values from a paper.
