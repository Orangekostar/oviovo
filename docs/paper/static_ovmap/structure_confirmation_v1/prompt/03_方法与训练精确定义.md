# 方法与训练精确定义

本文件定义本轮需要实现的新实验变体，不声称这些新ID已存在于仓库。实际数值接口依据固定父 `frozen_fc_routing/models.py` 和 `learned_object_readout/losses.py`。所有学习臂训练配置相同；只有下列指定差异。

## 1. 符号与共同数值路径

输入有效视图 v≤8、有效表面slot s≤64；raw维1536、semantic维768、metadata维8。令 c_v=fc_vectors[v]，`b=unit(mean(c_v for view_valid))`，保持原未另行归一化的 c_v 均值语义。

`h=embed(concat(local_unit,metadata))`，q=quality(h)，member mask由分组定义。每组softmax只在有效观测中计算，padding不能入softmax。空slot不建组。

学习组内权重a：`softmax(masked q)`；均匀a：`members.float()/members.sum(-1,keepdim=True)`，不调用quality得到数值，允许保留模块但冻结不用参数，禁止伪造梯度活跃数量。

`hbar=a@h_flat; keys=group_norm(hbar+group_ff(hbar))`。

标准值：`U=unit(phi(a@raw_flat))`；投影前置值：`U=unit(a@phi(raw_flat))`。对前置变体，phi(raw_flat)是不额外L2的投影向量，不是local_unit。只处理valid token，再scatter零；不要拿padding经过phi产生非零bias参与池化。

`e=4*tanh(queries@keys.T/sqrt(128))`，queries=4。rho恒1；membership不在损失或路由中。`alpha,null=parent.route(e,ones(J))`，`m=alpha.sum(-1,keepdim=True)`。

学习组间相对权重：alpha不变。均匀组间相对权重：`alpha=m.expand(-1,J)/J`，m由本臂自己的当前有效keys/e算出，**不detach、不从teacher取、不固定为1**。这保留整体修正强度的学习能力，结论仅指相对组间选择。

`z,delta=parent.correct(b,U-b,alpha,eta)`。训练eta=.5*min(1,completed_before_update/200)，推理.5。空local组回b；变体不能改变整体region分支。所有矩阵遵循父FP32路径，S_LL/V_LL应在同权重同输入短程检验与父head一致。理论重排公式不得替换父correct后又要求逐位等同。

## 2. G_LL：从训练开始不提供正确配对

取每view的validslot集合I_v。随机键为UTF8规范JSON数组：`["FG2_GROUP_CONTROL_V1", dataset_stable_key, condition_name, frame_id, 9173]`，SHA256前8字节big-endian作numpy default_rng种子。

- 在I_v内部作一次固定排列，用同一映射联合搬动local_raw/local_unit/metadata。
- local_valid不动；fc_vectors、view_valid、frame_ids不动。
- 不同view各自排列；同一对象条件frame在训练每次出现、不同prefix和测试时都用同一规则。seed17和29使用同一排列盐，避免模型seed和输入组seed混为一项。
- 不把class_id、membership、目标类别名称或correctness放进随机键。dataset_stable_key仅用于复现输入变换；新真实提案可用scene/frame/maskdigest，新GT诊断用固定匿名key。ID不作为连续/离散特征进入网络。
- 每view validtoken多重集、slot有效布局、每组成员数、组总数与S完全一致。排列可恰好保持部分对应，尤其singleton；记录实际破坏比例，不强制换随机种子直到得到最差结果。
- 保留metadata意味着网络仍可使用已有几何观测信息，所以名称为“打乱显式对应的等规模分组”，不是完全无几何模型。
- G必须从该输入分布训练。旧推理打乱结果只继承作历史，不算本轮G结果。

## 3. 两级四格与参数口径

LL=S_LL，UL=S_UL，LU=S_LU，UU=S_UU。对于性能P：

`inner_effect=.5*((P_LL-P_UL)+(P_LU-P_UU))`

`outer_relative_effect=.5*((P_LL-P_LU)+(P_UL-P_UU))`

两者之和为P_LL-P_UU。交互`P_LL-P_LU-P_UL+P_UU`单列，不能再次相加到平均边际上。数字要来自同数据、同seed、同checkpoint口径；matched1000为主，selected表另列。

相同初始化：先按父initialize(seed,{grouping:'SURFACE',direct_routing:false})构造模板，再deepcopy到所有FG-family变体；VIEW只改grouping，不重新创建子层从而移动RNG。均匀inner在前向不使用quality，梯度和weight_decay状态相应报告，禁止用unused参数数量制造同容量证据。GG比较S/G具备相同活跃结构；LL/UL是消融，不必声称活跃参数一样。

原membership头16641个参数无监督且rho恒1，不应宣传成新增机制，默认requires_gradFalse并保持初值；不得因此修改模板其他参数。原S/V精确训练复现时，optimizer保留父disabled会员无grad逻辑与模板状态，清楚记录冻结处理与数值等价。

## 4. MV_ATTN：可完整实现的学习式结构对照

**名称：受控逐视图Transformer读出，非CAMFusion原版复现。** 输入同一prefix内的region FC descriptors；不使用额外预训练模型、类别提示、图像或之后的view。几何信息间接存在于原提案/视图银行，不能叫“完全不利用几何的系统”。

具体实现：
1. `token_v=Linear(768,256)(unit(c_v))`，bias=True。
2. 4个独立初始化的pre-LN Transformer block。每block：`h=h+MHA(LN(h),LN(h),LN(h))`；`h=h+Linear(1024,256)(GELU(Linear(256,1024)(LN(h))))`。8head、dropout=0、bias=True、LayerNorm eps1e-5；批次维1、有效viewtoken无位置编码。不复制同一layer参数引用。
3. 一枚训练latent l shape[1,1,256]，N(0,.02)。`pooled=l+MHA(LN(l),LN(h),LN(h))`。attention权重默认不保存，避免没用tensor。
4. `r=Linear(256,768)(LN(pooled.squeeze))`，最后线性weight/bias全0；`z=unit(b+eta*r)`。eta与其他臂相同。这个自由值映射是对照能力，不描述为“冻结值空间”。
5. nn初始化在fork_rng(seed+701)内，之后恢复公共训练RNG。标准MHA/PyTorch module初始化按固定环境记录；使用显式math attention或已核对deterministic backend，禁止AMP/TF32；没有attention dropout。
6. 损失完全复用父base_loss；无新增多视图contrastive，因为它改变训练目标，不属于当前结构对照。参数/训练秒数和收敛曲线单独报告；不能用2,000步与原论文100epochs等同。

这个对照检验在本任务相同数据、骨干、样本抽取、监督下，逐视图描述符交互是否已经足够。CAMFusion原文有更大模型、PE/TextRegion输入、不同数据和多视图损失，因此**任何“超过CAMFusion”的结论禁止自动生成**。本轮不下载ScanNet++/PE或启动全规模外部论文复现；EXTERNAL_CONTROL_SCOPE必须列出这些尚未覆盖项。不得把没有跑官方配方伪装成其失败。

## 5. 三个无训练参照

### B_FC

完全调用父FrozenFCBase；无需任何新参数。无可用view时定义NO_OBSERVATION/unknown，不造一个零向量然后unit。

### B_SURFACE_MEAN

同七键、同真实表面分组，组内有效raw等权平均→phi→unit；所有非空组的u等权均值后unit为z。**不混入b、不学null或任何权重**。零local支持回B_FC。某个非空组或最终平均范数≤1e-12则按同预定数值不可用策略回B_FC并记数，不填任意方向。这是固定输入上的普通表面平均，不是原FG2-UU（后者保留可学习mass和锚点）。

### B_PFE_ADAPTED

从同一输入c_v构造unit region向量 f_v；`visible=local_valid & (metadata[...,0]>=0.5)`，表示该采样点位于预测mask内且几何可见。每个至少一view可见的site取 `p_s=unit(mean f_v)`；最终 `z=unit(mean p_s)`。退化零均值回B_FC并报告。

这里只在给定对象的最多64个采样点上组织区域描述符，**没有Open3DIS原文中跨所有重叠提案的逐点累积，也没有其原CLIP多尺度/Top5视图方案**。因此命名PFE_ADAPTED，不称Open3DIS完整实现，不据此宣称超越其论文分数。这个参照隔离“局部空间特征”相对“把同一region向量回投给多个点”的区别，但因权重、值来源和锚点也不同，不把差值完全归于单一因素。

## 6. 新头公共返回值与导出

每个实现至少返回 `embedding,base,fallback,view_indices,frame_ids,local_valid,group_count`。FG-family再返回a、alpha、null、U、energies、effective_rho、delta；MV返回明确NOT_APPLICABLE的组字段或不进入组分析，不能编造surface注意力。

train()与eval()都不读targets；外部score_record根据已有class_id算CE/margin。无训练静态方法也要输出完整未知/回退计数。指标生成器不能假定所有z都有loss_participating参数。

导出 `architecture.json` 含method/family/feature尺寸/normalization/残差定义/inputkey/permutation/版本；state_dict与spec/sourceSHA、text顺序digest绑定。创建同一模型两次load应对同输入输出一致。模型权重上传不含optimizer；恢复状态在OUT。任何checkpoint命名步数必须与内部completed一致。

## 7. 哪些结果属于方法作用，哪些不属于

- S/G的新家族matched1000差是正确显式对应的受控证据，不是低预算实时证明。
- LL/UL/LU/UU差是当前骨干与训练协议下的必要性，不要求所有模块必须贡献正值。
- S_PRE只是投影順序对照；若S_PRE更好，发布真实结果，不在确认后改主模型并复称预先锁定。
- selectedcheckpoint结果允许不同方法各自合理选模，但seed29不重选；matched-step表用于结构分析。
- 新confirm若仅GT-support有优势，主张必须限定输入支持；真实稀疏提案的低recall不得通过删除未匹配实例改善。
