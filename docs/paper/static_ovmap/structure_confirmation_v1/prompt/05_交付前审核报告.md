## 2. 审阅过程中已修正的问题

1. **确认不只是S/V/G三臂的固定步比较。**两级消融若只比较不同selected步，仍混入选模影响；最终保留全部8训练臂的step1000确认结果。因此额外matched槽为16，最大真实AP池由25改为35，最大行数改为420。
2. **成本测量不能挤进200次工程head上限。**19槽×16对象×3prefix×(warmup1+repeat3)=3648，新增独立成本head上限4000，防止执行到测量阶段才被额度阻断。
3. **确认调用量重新核算。**GT诊断上限768原件×4条件×3prefix×19selected，加真实768×3×19，再加两类支持的16个matched槽，总上界280320，低于300000授权上限。
4. **全部模型的相同seed初始化只对FG-family成立。**MV_ATTN使用独立fork_rng，不宣称和FG2同容量同state；但数据draw与监督预算配对。
5. **静态表面均值与S_UU不再混称。**前者无训练无base-anchor，后者保留可学习总修正质量；两者是不同的必要对照。
6. **新场景不能复用旧map入口而伪造parent capture。**指定重建表面辅助的真实proposal AP；完整新在线地图未在本合同实现，不虚构结果。
7. **权重与caption不重复判定新颖性。**D2、E/R旧结果只继承，成功也不将其全部归为S；新确认不与GT诊断混分母。
8. **预先定义了真实依赖分支。**原授权下载证据缺失、某CONF缺文件、CUDA环境缺失等都保留完成部分并发布PARTIAL；不能生成随机数据“通过验收”。
