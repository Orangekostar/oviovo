## 二、此次源码核查后的四项实质修正

| 问题 | 原先想法的不足 | 本执行版的修正 |
|---|---|---|
| FC与OVR温度不同 | 直接用各自log概率相减，会把表示变化和温度变化混在一起；两模型原分数完全一样时也未必零残差 | 主方法固定共同FC温度计算分数差；另设不同温度的CALDELTA对照 |
| N0保留十个观测，但实际只用最后八个 | 直接拿全部retained IDs分析相关性，会将未参与分类的观测混进去 | 读取原saved顺序、至少两观测条件、最后八个feat与area；Q只读实际最终retained集合 |
| FC/OVR有效视图可能不同 | 直接相减可能只是看到的视图不同，不是微调增量 | 按真实请求、mask、图像和原面积求成功视图交集；相同集合可复用原分数，不同集合重算双方聚合；缺交集保持基底并明确计数 |
| 新依赖方法带基底正则 | 如果只比不带正则的logit融合，收益可能只是来自基底保护 | 加入D1_ANCHORED，使用完全相同的类别图、正则与归一化对照 |

进一步明确：协方差是“观测扰动敏感性＋同图支持重叠”的正半定代理，不是真实语义误差协方差。不同视觉模型的向量不能直接相减或作交叉协方差；第一版仅建模同一视觉空间的N/Q关系，F的跨模型误差相关性没有被覆盖。

## 五、为什么不是把数学公式写得更复杂

主方法的每一步都有可被否定的命题：

- 局部残差若不如全局残差或普通预测混合，就不能强调局部机制必要。
- D4若不如同样有anchor的D1、D3或打乱相关系数的D4，就不能将收益归因于有用的依赖关系。
- 如果真实共享观测很少，D4与D3同分是机制没有被充分激活，不应继续包装成成功去相关。
- 所有这些算子可能仍然改坏正确对象。正半定、唯一解、概率质量守恒等数学性质不推出AP提高。
- KL更新、对数比、最小方差和图排序均有前作；原创候选在配对三维区域证据与具体观测依赖的利用，不在基本算子名字。

提供的`math_reference.py`已经做了12项合成算子检查，有限差分Jacobian最大绝对误差约2.75e-10。它们只验证代数实现边界，不是模型、数据接入或benchmark测试。
