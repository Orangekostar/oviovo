# SAM-V局部对象再分割：源码审核与任务拆解

## 1. 本轮做什么，不做什么

这是一次四场景的模块可行性实验，不是新一轮完整26场景benchmark。
研究问题：SAM-V在mask生成阶段引入的多视图信息，能否提供原地图没有正确
组织起来的对象支持；同一普通FC读取这些mask时，能否取得更有用的语义。

固定场景：office1、room0、scene0011_00、scene0050_00。
每场景最多8个已经输出的G1对象，每对象一个自动提示锚帧、最多3个正点、
6个固定视图。默认不训练，不改变三维表面，不更换分类骨干，不扩展场景。

六个主条件合计24条输出／12个双场景池化；另存D2的四条父参照／两个新子集
池化，共28条逻辑记录／14个池化。新增的“原mask同视图FC”控制是必要的：
否则原方案不能区分收益来自新mask还是额外读取了同一物体的图像。

这些场景均已用于开发，不能称为未曝光测试。即使全部涨点，也不能将双场景
池化写成完整Replica8/CF18结果；本包没有自动扩到26场景的权限。

## 3. 固定实验与归因

| 条件 | 支持范围 | 语义 | 回答的问题 |
|---|---|---|---|
| SV00 | 当前G1 | 当前G1 | 完整参照 |
| SV01 | SAM2局部再分割 | 原类别 | 普通视频传播是否足够 |
| SV02 | SAM-V局部再分割 | 原类别 | SAM-V对实例支持的作用 |
| SV03 | 保持G1 | 原mask、同两视图普通FC | 额外观测的控制 |
| SV04 | 保持G1 | SAM-V mask、同两视图同FC | mask改变是否改善语义输入 |
| SV05 | 精确SV02分区 | 精确SV04类别决策 | 结构与语义是否互补 |

SAM-V只产生一套实际mask，SV02/04/05共用，不重复跑三次。SAM2与SAM-V使用
同一组JPEG解码图像、正点和时间顺序。SAM2明确使用SAM2.1-L，不用示例默认B+
搭配Large权重。为避免可选CUDA连通域扩展差异，基线明确保留动态稳定性与
点提示记忆处理，关闭小孔填充；因此不声称复现作者的整套SAM2论文行。

## 4. 这次对“保护旧结果”的定义

三维坐标、三角面、TSDF不变；不等于所有旧mask都不变。否则SAM-V提供的新
边界无法生效。本轮允许选定对象的局部边界修正，以及未选择对象的两圈边界
顶点转移；保护未选择对象内部、提示点所属源行、域外与未观测区域。

新增范围由原支持AABB外扩0.30米限定；源行在至少两视图中可见，正票比例
至少2/3才可加入，负票至多1/3才可移除旧对象的已观测部分。多个目标同时
仲裁，平票保持旧归属，禁止顺序叠加造成结果依赖遍历顺序。

这些是待验证的实验规则，不是已证明最优的数学定理，也不保证AP不下降。
必须分别保存raw支持、规则允许的支持和最终互斥输出。如果raw支持有价值却
被边界保护挡住，要如实指出，不把适配器的局限写成SAM-V没有能力。

语义控制只在两来源、两固定帧都能形成有效区域表示的共同对象上比较；
不换视图、不读GT。若失败，两语义条件都保持旧类，失败数量独立统计。
新协议允许整个已输出对象统一改类，包括原raw-zero绘制边界；这不再是旧版
受保护改类协议，不能直接抄SU/IR分数进入本表。

## 5. 任务顺序

P0 绑定四场景真实G1/D2、RGB-D/相机、分区和模型资产。
P1 用原32个姿态代表帧规划对象、自动点、6视图组、局部可改域。
P2 两个真实工程试测，不用AP选参数；必要时仅因真实OOM全局改成4视图。
P3 冻结代码与资源档，完成SAM2/SAM-V实际分割。
P4 共享几何提升、配对FC重读出，生成六条件完整地图。
P5 同原评测器评分，分析唯一匹配、改对/改错、被限制的提议与成本。
P6 生成三表、交接，正常推送新分支并核对完整SHA。

旧图、旧实验、旧缓存只读。若父数据路径变化，用明确path-map定位同内容；
不靠文件名猜测身份。权重只从作者声明来源或已验证本地副本绑定。

## 6. 实际资源与验收范围

最多32个对象窗口、192个SAM-V科学输入帧槽、32条SAM2独立双向轨迹。
最多64张不同的原图FC输入与128次原/新区域pooling；能读取匹配dense缓存
则不重复编码，但新区域仍需真实pooling。新增AnyUp、N/Q、CropFormer、
建图和训练均不执行。最多128个原尺度源行观察；有精确父缓存时可复用。

额外只做8次分割窗口计时：两个固定试测窗口×两模型×两次。它们不是完整
恢复耗时，不与旧G1每场景秒数比较。不立即进行64次完整方法冷测。

执行包只进行轻量数学与规格检查；CodeX仍需少量真实模型检查。不做全仓
回归、模糊测试和成千项重复哈希。执行失败与科学空mask必须区分。

## 7. 结果如何决定下一步

候选SV02/04/05需在两个双场景队列中五项不低于G1，并跨过对应D2的CF子集
APall/AP50要求，才是通过本轮晋级条件。还必须检查是否超过关键简单控制：
SAM-V支持对SAM2；新mask语义对原mask同视图FC；组合对单分支。

无通过者保留G1。即使模型有raw-mask改善但正式AP没有改善，也只能记录
局部可行性信号，不能宣布最终方法成功。本轮到发布为止，不自动再跑26场景。

论文层面的增量若要成立，还需后续证明地图自动查询与输出更新超出SAM-V
直接接入的价值。此次使用外部训练模型，本身不是我们发明新的多视图分割器。
