## 当前决定的性质

- 已核实源码事实：full200分数导出无损而embedding省略；旧H为micro；MV自由更新无半径约束；旧proposal/score有固定计数。
- 设计选择：A的110候选、LOFO和门槛；PSEUDO8/CORE152；共同中心、有限128步凸包层；新12seed×32mask。它们不是已测事实或学术界通用阈值。
- 待执行：旧score实际诊断、A门槛、真实数值工程、B训练、C新确认、REG和远端发布。不能把本包合成检查当成真实实验。

## 调用链

旧公开 scores manifest → prediction_codec → GT lock columns/key → class角色 → A排名/混合。原OUT NPZ embeddings → A夹角，不做text伪逆。
旧TRAIN/DEV manifest → core_class_split → 新draws原索引域 → shared sparse tensor → frozen dictionary/center → 同网络q → 三输出算子 → 新CE152与macro-H选模。
RAW/POST锁 → 已曝光REG固定G1 → original scorer。C门槛通过 → 新family锁 → 授权raw → label-free geometry/SAM → 真实预测锁 → GT解析/诊断 → full-GT稀疏AP。
所有科学完成/负结果/部分缺项 → 三轴主张账本 → 一次审核 → 正常C1/C2。
