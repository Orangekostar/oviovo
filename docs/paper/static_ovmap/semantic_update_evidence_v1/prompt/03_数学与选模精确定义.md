# 数学、选模与因果边界

## A. 旧结果诊断

### A1. 输入与排名
原cosine向量s与valid_ids严格对齐；全200排名采用稳定排序：分数降序，再沿冻结valid_ids原行号，不能任意更换tie类。未知样本defined=False仍为unknown=0，所有准确率计错；其NLL、向量角度、子词表排名为空。
对真实novel样本：记录full_rank、novel_rank、top_all是否base、top_novel正确与否、FC对应字段。novel子集仅诊断；正式推理永远200类。
novel内部top1正确而全词表错误是竞争抑制的描述性计数，不是已识别的因果机制。即使校准可恢复，也不叫“表示未改变”的证明。

### A2. 分数混合、校准、角度
MIX：`s=(1-alpha)*s_BFC+alpha*s_MV-gamma*I_base`。不L2归一化这个分数向量，不一条用prob另一条用cosine。
CAP：b和z必须是真实单位768向量，令θ=acos(clamp(b·z,-1,1))。θ≤τ返回z；否则 t=z-(b·z)b，返回cosτ b+sinτ t/||t||。τ=180原样；完全反向且||t||<1e-10，回b并记ANTIPODAL_FALLBACK，不人为选择一个有利切方向。随后用冻结文本重新评分并减gamma。
A角度上限与B归一化前radius不是同一个算子。不能把CAP结果当“同原始残差范数”实验。

110是两族55+55逻辑候选，完全相同输入/输出可以复用，不能据相同准确率推断alias。候选平局顺序：H_macro、min(B_macro,N_macro)、B_macro、最少非恒等操作、固定candidate_id。操作数定义：alpha∉{1}的混合计1（alpha0仍算混合）；finite cap<180计1；gamma非0计1；单独BFC作独立常数参照。

### A3. 指标
某集合K的macro accuracy：对K中有正样本的每类先算clean正确比例，再类均值。`H_macro=2*B_macro*N_macro/(B_macro+N_macro)`，两者皆0为0，任一无正样本为null。`H_micro`用普通样本准确率单列。
原件abstention计错；class无样本不人为填0，记录支持classIDs。LOFO selection与pooled OOF都重新按原件算macro，不把家族macro当成相同的指标。每family辅助H允许类支持集合不同，报告该差异。
A参照S/G只有matched1000、clean8V，不从它们的所有checkpoint/prefix找最好点。A_GATE是预算政策，不是论文显著性检验。

## B. 同网络、同输入的输出约束

### B1. 字典与共同中心
原七键输入产生b=原FrozenFCBase。对于每个有有效观测的surface slot，等权raw池化、冻结phi、L2，得u_s。这个字典与网络参数无关，用no_grad生成一次并在CPU缓存；每condition/prefix独立身份，不能clean字典用于corrupt。
D的行是[b,u_1,...,u_m]（最多65），均为单位向量。a_ref=[.98,.02/m,...,.02/m]，c=a_ref D。||c-b||≤.04，||c||≥.96。
无local支持时三学习臂一律返回BFC，不让E独自回退；训练时可返回b+0*q保持零损失梯度路径，仍按原16项分母累积，不因无梯度样本报假技术失败；无view则全部unknown。不可归一化的非有限字典条目不是自动丢弃难例：nonfinite为技术失败；有限零范数组按固定不可用策略排除并登记，若全空共同回退。重复证据保留，不以GT去重。

B_C0=unit(c)是必须静态对照，用于识别共同初始化带来的贡献；B_FC保持父单位b。

### B2. 共同网络
region tokens=unit(fc_vectors[valid])；evidence tokens=u_s；另有b token。三者各经同一个Linear(768,256)，加3×256可训练type embedding；顺序[b,regions按原frame顺序,U按slot顺序]，不加位置编码。三臂都有全部tokens，不让约束臂多看局部证据。
继承AttentionBlock的pre-LN4层、8head、FF1024、dropout0。latent 1×1×256与原MV pooling同式；末Linear256→768 weight/bias全0。type embedding与latent N(0,.02)，参数构造在fork_rng(seed+3701)，三臂deepcopy同一模板。不能把每层写成共享引用。
共同候选q=c+eta*rθ，eta沿父坡度，推理.5。网络只处理观测tensor，不输入真实类别、base/novel标记、datasetID或family。type仅指token来源。
模型层接收七键，内部字典可缓存于独立adapter；缓存内容必须可由这七键和phi产生。外部hash不作为token。

### B3. 三个算子
FREE：y=q。
RADIUS：y=b+t(q-b)，t=min(1,.5/max(||q-b||,1e-12))。
EVIDENCE：先计算有限128步的单纯形系数，再对得到的p施加相同RADIUS。
最终z=unit(y)，文本完整200类余弦评分。
所有差别只在算子；损失、网络、输入、radius、共同c、初始化完全相同。不能向E另加label保持loss或更强teacher。

### B4. 有限凸包层：精确定义，而非模糊“求一个投影”
近似目标：min_{a>=0,1ᵀa=1} 0.5||aD-q||²。无额外熵/距离正则。
预计算K=D Dᵀ、L=max(lambda_max(K),1e-8)，D/K/L均detach；rhs=D q，必须对q保留梯度。
a_0=y_0=a_ref，t_0=1。k=0..127：
```
a_next = simplex(y_k-(K@y_k-rhs)/L)
t_next = (1+sqrt(1+4*t_k*t_k))/2
y_next = a_next+((t_k-1)/t_next)*(a_next-a_k)
```
最后p=a_128 D。simplex是标准排序阈值投影，返回非负和为1，不用softmax替代。固定展开，禁止STE、detach迭代状态、只在推理投影训练时不投影，或用GT挑solver超参。
返回FW_gap=max(0,a·g-min(g))，g=K a-rhs；它是凸包目标的诊断，不是“泛化误差”。不要在正式模型中逐样本改变迭代步数；128是模型定义的一部分。
E后续radius裁剪系数为a'=(1-t)e_0+t a，故归一化前y仍在conv(D)且距离b≤.5，范数≥.5。**归一化后的z一般不在原欧氏凸包内；只能称normalized feasible evidence combination。**
顺序投影+半径裁剪一般不是 `argmin_{conv(D)∩ball} ||y-q||²`。文档、摘要、图中均不得称“精确交集最优解”。06给出可执行CPU参考和有限差分检查。

FP32主路径；Gram最大特征值在字典缓存时一次算，不在每个micro重复。128步/梯度/投影成本单记；单纯形只用PyTorch张量操作，不要求新增CVXPY/CUDA环境。
真实数值核对比较128与256步；若无法达到预定技术精度，停止B而不是自动改科学定义。已训练checkpoint可在固定两个工程输入上记录FW_gap，不为不同臂追求不同容差。没有全数据最优性保证。

### B5. 共同初始化的理由与边界
若初始q=b位于凸包极点，某些投影实现会出现零梯度/非光滑问题。使用固定c使三个算子从同一相对内部凸组合开始；06只证明特定合成输入上的梯度，不保证所有真实字典的秩或所有模型一直有梯度。
三臂初始输出比较容差1e-6，而非要求不同算子计算路径逐位相同。BFC与BC0并不必相同，两者都报。
不可仅因为FREE和E参数相同，就声称有效函数类、优化难度或算力相同；这些正是本轮操作差异的一部分。

## C. 新选模与数据作用

### C1. 类别与损失
原base160拆为CORE152和PSEUDO8，原novel40不变。CORE的正实例且有支持才抽样，但原完整列表序号不重排。统一draws只对CORE类做均匀类→原件采样。
所有CE仅CORE152，不将PSEUDO或原novel原件用于保持loss；四条件输入与父方法不变。原FC初始化确实可能在预训练中见过这些类，不声称零知识，只称本轮监督未使用。

### C2. 三套模型状态
每臂RAW选择5步中的H_macro最佳；POST选择5步×110配置中的最佳；固定1000作额外结构比较。seed29三套状态都继承seed17的step/后处理，不另外选。
RAW平局：H_macro→min(B_macro,PN_macro)→B_macro→earliest_step。
POST平局：H_macro→min→B_macro→least_operations→earliest_step→candidate_id。
SIMPLE_STAR只从FREE_POST、RADIUS_POST、BFC、BC0选，不能包含E或GT oracle。static平局优先BFC、BC0、FREE_POST、RADIUS_POST。
如果alpha0胜出，此POST就是BFC相关校准，明确不构成E机制证据。RAW与POST必须同时展示，禁止只给后处理最好点。

### C3. 新确认门槛
本包C门槛只用DEV的CORE/PSEUDO，不能用B_REG或原novel40选择。严格门槛满足与否不等于CVPR价值保证，也不等于未满足就普遍无效。所有臂0.5pp/1pp值是本次预先资源政策。
C未开启不获取新场景；C已开启且模型锁定后，不能通过看GT支持或分数决定只评价某些对照。

### C4. 更新方向分析的正确说法
A/CAP只比较最终夹角。B/RADIUS保证同一最大半径，不保证两个模型每个对象的实际||y-b||相同。必须报告实际角度/范数分布与匹配区间的结果；若E优势只伴随更小实际改动，不能把全部差值归给方向。
最终即使E胜过R，也只能初步支持这个具体有限算子在当前控制下有价值。更广泛结论仍需合理近邻、真实应用和独立性说明；几何凸包不等于语义正确区域。

POST操作不改变RAW算子验证，但其分数通常不能解释为同一可行集中的单位embedding。任何正式性质只绑定明确的RAW输出，POST只作为可比较的识别系统配置。
