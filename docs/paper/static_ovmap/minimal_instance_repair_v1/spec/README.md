# Minimal instance repair — Codex execution package

Entry point: **CODEX_FINAL_EXECUTION_EN.md**. Numeric authority: **PROTOCOL_SPEC.json**.
The English contracts and evaluation document are part of the same instruction.

This package specifies experiments to implement and run on the user's server. It
is **not** a report of newly completed mapping experiments. Source review is pinned
at `Orangekostar/oviovo@247e1e9782d43e882589bd9ab0015d513c200e49`.

The task tests residual-to-incumbent attachment, bounded object regrouping verified
on disjoint observation views, and boundary-stable rereading of incumbent objects.
It keeps the surface mesh, original D2 readout, original G1 v2 baseline, evaluator,
benchmark cohorts, and inherited model/text parameters fixed. Instance membership
may change in named structural arms; this is explicitly a **new method study**, not
an exact-prediction runtime patch.

Files:
- CODEX_FINAL_EXECUTION_EN.md — work sequence, executable CLI, scope and publication.
- IMPLEMENTATION_CONTRACTS.md — exact proposal, verification, rereading and export rules.
- EVALUATION_AND_SELECTION.md — diagnostics, pooled evaluation, target and timing.
- PROTOCOL_SPEC.json / EXPERIMENT_MATRIX.md — machine constants and fixed comparisons.
- CODE_REVIEW_AND_PLAN_ZH.md / SOURCE_EVIDENCE.md — rationale and inspected source anchors.
- reference_kernels.py / test_reference_kernels.py — small specification checks, not production code.
- AUDIT_REPORT.json / REFERENCE_TEST_LOG.txt — local package audit results.

Do not deploy automatically. Do not replace real negative outcomes with a new
search. The fallback research reference is G1 v2, not a per-dataset mixture.
