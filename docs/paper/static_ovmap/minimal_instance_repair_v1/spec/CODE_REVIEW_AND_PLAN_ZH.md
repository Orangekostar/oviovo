# 最小实例修复与已有实例语义重识别：源码审核与任务安排

日期：2026-10-07。源码锚点：`247e1e9782d43e882589bd9ab0015d513c200e49`。
仓库：`Orangekostar/oviovo`。本文件是研究执行设计，不是新实验报告。

## 1. 本轮解决什么问题

已有结果提示：固定恢复区域中，CF18 的 132 个可用候选有 131 个最佳类别无关
IoU 不超过 0.5；Replica 为 37/42。这里评价的是实际导出的残余区域 K，不是
所有原始 owner 的完整支持 R，更不是整张地图的重建上限。此统计来自当前分支
`EVIDENCE_EXPLORATION_CLAIMS.md`，生成机制见 `analysis.py:baseline_scene`。

因此，本轮从“换一种方法给同一碎片分类”转向两件事：

1. 根据多视图证据，判断残余是否应归附已有对象、与其他残余构成一个对象，或保持原状。
2. 将已经有效的普通 AnyUp 用到已有实例的语义重识别，再检验边界稳定性是否能减少错误改类。

这次保持 **XYZ、三角面、TSDF、位姿、目标空间投影和评分协议不变**，允许新的实例
分区。因此，不能继续宣称“所有旧 mask 不变”。正确的限制是：原有实例的核心行
不转移给其他实例，局部归附可以扩大其支持；新重识别可以改变其类别。

## 3. 方案比上一条概念建议收紧了哪些地方

**不一次解决所有实例结构错误。** 首轮只使用完整 K 和完整 P 单元，最多四个单元
一组、最多一个已有实例；不拆 raw owner、不合并两个已有实例、不转移已有核心行。
若 R/K 诊断表明主要机会需要违反这些限制，要记录为后续方向，不把它偷加到本轮。

**提议和验证使用不同姿态组的观测。** 每场景最多 32 个代表帧，先由位姿固定，再
偶数/奇数索引分成两组。它们都是同一序列的观测，原地图也看过这些帧；这里检验的是
“没有参与新假设生成的视图”，不是从未使用过的数据，也不提供统计独立保证。

**先锁定假设再分类。** 带已有 host 的归附直接继承 host 的 D2 类别；没有 host 的
残余组合，只有入选后才用一张新 union 区域做 FC 识别。分类不会反向决定生成什么组合。

**对照访问相同的候选库。** 直接重组与验证重组共用同一库、同一优先级；普通重读出
与边界稳定重读出共用相同对象、两张 FULL 视图和提议类别。不让新方法隐蔽多看候选。

**改变支持要改变缓存身份。** 新几何分区、mask、评分登记都必须生成真实身份。
表面 GeometryIdentity 可以继承，因为坐标没变；owner 分区不能继承旧哈希。

## 4. 固定九种方法

| ID | 方法 | 要回答的问题 |
|---|---|---|
| IR00 | D2 | 不恢复的强基线 |
| IR01 | 当前 G1 v2 | 需要保护的当前完整版本 |
| IR02 | 最近表面归附 | 几何最近邻是否已经足够 |
| IR03 | 同体/分离证据归附 | 二维观测是否减少简单归附的错误 |
| IR04 | 正向共识库直接重组 | 只根据多视图正向关系重组的效果 |
| IR05 | 不同视图验证的最小修复 | 检验另一组观测与修改代价是否值得 |
| IR06 | 已有对象普通 AnyUp 重识别 | 表示改善用于原本有实例支持的对象是否更有效 |
| IR07 | 边界稳定重识别 | 同对象核心、完整区域与前端交集是否减少错误改类 |
| IR08 | IR05 结构 + IR07 语义 | 两种干预能否互补；不额外调参 |

这是固定 slate，不再要求临时判断“哪一路值得试”后才能继续。技术试测不做参数选择；
全部主结果用于已曝光队列的探索性比较。较此前八配置建议增加了一行固定组合，但
整体保持和上一轮一样的 9×26=234 条规模，不额外接入训练数据或新 mapper。

## 6. 计算控制

最多 26 张共享已有地图、832 次额外科学观测投射、832 个科学新 FC 帧输入及 832 次
AnyUp Q/K；实际通常受对象数、视图数与共享缓存限制而更低。上述不是时间预测。
G1 基线冷调用本身的投影、模型输入与试测单列，不拿科学缓存上限冒充全部实际成本。

每场景最多64个修复 seed、96个组合假设、每结构臂8个操作；最多16个已有实例重读出。
Union 只编码 IR04/IR05 已选中的候选；IR08 直接组合结果，不再做视觉推理。
普通 AnyUp 不执行上一轮失败的 owner/depth 因子，也不为报表计算无用的变体。

推理使用一个绑定的 A40 进程、继承环境和原 FP32；CPU 观测最多2个进程，评分3个，
BLAS和raycast线程各不超过4。ENOSPC 先检查并通过新任务 storage-root 安排存储，
不删除历史数据。不要全仓回归、对所有旧缓存重复哈希、无限重试或堆测试数量。

## 7. 选模与预计作用

要求相对当前 IR01，两队列各五项不下降；CF18 APall 严格超过 D2，AP50 至少达到 D2。
按未取整 fraction 和 1e-10 浮点容差核对；0.10pp 只作为另列幅度标记，不是显著性。
简单对照可以获胜；无人通过就保留 IR01。所有新场景仍沿用已曝光属性。

| 路线 | 合理的目标预测 | 可能失败的原因 |
|---|---|---|
| 归附 | 某些小残片不再重复计为新物体，扩大合理 host 支持 | host 找错或二维分割也过分割 |
| 重组/验证 | 某些组合跨过实例 IoU 阈值，同时减少错误合并 | 正向组合库无完整对象、验证视图不足 |
| 已有对象重读出 | 几何可匹配的旧对象改对类别，产生更直接 AP 收益 | 强模型仍认错，或稳定性偏向旧错误 |
| 固定组合 | 分区与类别改善分别成立后形成完整收益 | 局部好处被误合并、误改类或排序改变抵消 |

不能预先承诺涨多少，更不能保证保住 Replica。结构不变的核心行只是工程性质，
新增支持、类别和官方面积排名仍然可能造成任何指标下降。

## 8. 最终论文证据

主文继续三表：完整性能、机制必要性、同边界成本。结构改动的真实性要由唯一GT匹配、
高阈值IoU、旧匹配损失、受影响支持量体现；不能只说“碎片数少了”。语义改动必须同时
报告改对/改错，不把评分条目误称为真实对象数。

本轮不是 MaskClustering 或 MV3DIS 的完整复现。多视图共识、区域上采样已有前作；
拟议区别是已有语义地图上的局部角色修复、不同提议/验证视图，以及边界稳定语义判断。
是否能构成新颖性，需要它们真正胜过 IR02、IR04、IR06，而不是名称或测试数量。
