# 下一轮任务：资格恢复、低风险关联与候选保护

## 结论与范围

以本轮重建的 **BB00_NATIVE＋D2** 为唯一主参照。不是继续把已失败的BIDIR堆得更复杂，
也不是预设所有模块都要保留。本轮的最终目标是完整输出在官方池化APall上有实际净收益，
同时明确AP50和mIoU的取舍；所有推断必须经过实际预测验证。

主任务入口为英文 CODEX_FINAL_EXECUTION_EN.md；JSON固定数值，contracts固定接口语义。
当前包是任务规格，未运行新的模型或完整地图，不代表已经获得涨点。

## 二、实验矩阵

### 低成本部分：原地图不动

| 条件 | 改变内容 | 要排除的解释 |
|---|---|---|
| B_D2 / B_FCEQ | 直接使用真实历史控制 | 不用不同轮次的小数漂移制造增益 |
| W040 / W045 | 只在真实FC_EQ与D2之间插值 | 简单配重是否已经足够 |
| U1_NATIVE_SINGLE | 原生单观测解除输出资格限制 | 简单资格恢复是否足够 |
| UQ_PAID_QUERY | 只使用已有Q最终分数补遗漏对象 | 是否已有付费信息被输出登记挡住 |
| U2_FC_MATCHED_SINGLE | 对U1同一对象、同一视图使用FC | 将新增识别能力与增加视图分开 |
| U3_FC_CAPTURED | RAW遗漏对象，最多3个合法历史请求 | FC独立访问几何实例是否补回有效输出 |

每个U条件只增加自己真正有证据的遗漏owner，不无条件拼接U1/UQ/U2/U3。原有owner不扩张、不合并、不被新对象抢占。
U方法不是“更强TSDF”，是固定原始几何上的输出恢复。模型置信度高也不保证新对象是真物体；新增FP要计入完整官方分数。

先不引入最终网格重投影合成新视图：没有合法captured请求的对象如实标记。已有数据足够检验第一轮资格恢复，
避免把新视图生成、识别方式和输出资格三个因素一次混在一起。

### 真正改地图：三种关联、两种SAM输入策略

| 条件 | 主要干预 | 对照意义 |
|---|---|---|
| A1_NATIVE_FALLBACK | 保留原forward匹配；未匹配走原生路径，不提前强制新建 | 单独检验错误回退是否造成损失 |
| A2_MULTI_FREE | 局部各选一个已有owner，允许多个局部指向同一owner | 先用简单版本检验一对一容量是否有害 |
| A3_MULTI_UNION | 在A2上加指向性、歧义差值和联合反向覆盖 | 检验约束是否在自由多对一基础上减少误合并 |
| S1_CROP_PRIORITY | 完整保留当前CropFormer候选；只用已缓存SAM胜出像素补未标区域 | 防止局部重叠压掉完整候选，不需要新SAM |
| S2_CONFLICT | 在S1上，用自身地图的历史稳定身份检查明确跨物体冲突 | 只去掉有反证的SAM补充部分，未知空间不作为负例 |

S1不是把旧discovery阈值从0.2随意改到0.8后切剩余碎片，而是完整候选优先。
S2不读取其他实验最终地图作为在线先验，不把不同二维编号自动当成不同物体。
A3也不是直接把双向Hungarian换个名字：联合覆盖在多个局部部分的并集上计算。

## 三、阶段与计算规模

1. 绑定原12个场景的原生地图、来源、模型及缓存，先完成W/U的4场景开发实验。
2. 三种A在4个开发场景做真实地图；S1有真实前端改动时才执行两种S。
3. 每个结构先完成4场景原始几何诊断。严重几何恶化才停止该条件的N/Q/FC；轻微取舍不能被误杀。
4. 选择最多一个满足开发净收益条件的主干，再迁移8个Replica场景；没有候选时不强推新地图。
5. 轻量部分仍在8个Replica上完整运行冻结的单项；最多一次W×U组合、一次主干×轻量方案，不搜索A×S全组合。

新地图上限：5×4开发＋1×8迁移＝**28张完整map-scene**。旧BB00地图不重复重建。
新增恢复候选最多128/场景、3视图/候选、32个缺失FC整帧编码/场景应用。
FC缓存存在不代表整个方法免费；全量新地图的N/Q/FC重提取单独记账，不受小型恢复预算冒充限额。
所有新SAM、CropFormer和文本模型前向均为0；整轮仍可能有FC与新地图N/Q的GPU推理。

## 四、指标目标与选模

开发选择采用同一四场景官方池化；原始值是0–1，百分点阈值必须除以100。
净收益晋级：APall至少+0.20pp，AP50与mIoU均不低于基线0.10pp以上。
这是事先规定的工程取舍，不是显著性证明，也不等于五项指标全面提升。
APall、AP50、AP25、mIoU、mAcc仍全部汇报；最终有小幅负项时必须写取舍。

可行集合中，使用APall 0.05pp / mIoU 0.10pp / AP50 0.10pp带宽，再比较计算与简洁性。
原生D2始终是候选。允许简单UQ或配重胜出，不为了维持“创新点”强留新算法。
四个开发场景及Replica都已曝光；Replica不能倒改开发提名，部署仍不自动替换。

## 五、特别防止的三种假成功

**只增加候选数量。** 新对象必须进入正式mask清单和原评价器，统计新增TP/FP及旧匹配损失；不是数出更多owner就算提高。

**只在Python里回退。** C++不得继续对未匹配组预分配新owner，或用全体历史owner的硬token阻止原生alias。

**只改概率或改编号。** 需要分别报告概率差、类别差、物理owner划分差、评测身份；相同预测直接复用，不能把输出等价包装成新证据。

## 六、可保留的科学解释

若U有效：支持“原生语义资格不是其他来源可识别性的必要条件”，但不能说恢复了不可见几何。
若A1有效：支持未匹配不宜直接认定新物体；若A2/A3进一步有效，才研究局部过分割与全局实例的兼容关系。
若S有效：支持当前候选保护及明确冲突过滤的具体设计，不代表复现了完整SAM/OnlinePG论文的效果。
若只有W有效：保留更简单的配重，不把它算到主干改善名下。
