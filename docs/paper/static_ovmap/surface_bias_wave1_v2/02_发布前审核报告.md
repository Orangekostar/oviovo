## 4. 参考代码核验与使用限制

`reference_bias_solver.py` 与上轮ZIP中的参考字节一致，本轮只做一次重新自测，12项通过。它没有访问仓库数据/FC，也没有Git发布功能；不能直接当作完整任务入口。

参考脚本允许strength到1，服务于“完全去掉已知合成bias”的单测；生产lambda只能取本包固定四个值。参考脚本不实现C1/C2、供体清除、选择状态机、map集成和Git发布；这些明确由Codex按主指令开发。不要把参考CLI的对象NPZ输出当成最终实例地图。
