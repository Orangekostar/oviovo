# 源码审核与执行方案：保留来源的语义更新

## 1. 这次任务与上一轮的区别

这轮只检验“同一份新语义证据怎样进入原系统”。不修改几何，不继续做残片归附，不生成新视图，也不训练风险判别器。当前固定基线为 `b000355eb8f91491e002df1499bd0170d91c35ef`。

已发布结果表明，IR06在CF18优于D2，却明显损伤Replica；IR07部分减轻Replica损失，同时减少CF18收益。源码中 `reread_decision()`依据新FULL区域的均值和旧类别进行硬改类，并未把旧N/Q/F的完整概率继续用于最终竞争。这支持优先检验“保留来源”，而不是继续增加一致性硬门槛。[S02,S03]

这只是有根据的研究假设，不证明融合一定能同时提高两套指标，也不证明此前损失完全来自覆盖旧证据。

## 3. 五种新接入方式

三路齐备时，原D2：

\[
p_0=0.25p_N+0.25p_Q+0.5p_F.
\]

A为新FULL视图的普通AnyUp语义，C为完全相同FULL视图/mask上的原粗FC语义。两者经过原FC文本空间、同一冻结T_F进入类别概率。

| 新条件 | 三路齐备时的含义 | 要检验什么 |
|---|---|---|
| SU04 | 保留N/Q，仅F→A | 是否有必要保留旧裁剪证据 |
| SU05 | N/Q/旧F/A各占0.25 | 旧F是否仍有价值 |
| SU06 | 与SU05相同，但A换成同视图粗C | 新表示是否优于只是换视图 |
| SU07 | 0.75×整个D2＋0.25×A | 相同A权重下，来源内更新是否比普通集成好 |
| SU08 | 只对F加入0.5×(同帧A−同帧C)/T_F的残差，再与原N/Q组合 | 是否应利用表示变化而非重复累计全部新证据 |

SU08减去的是新C，不是历史F。后者视图集合不同，会混入选视图变化。SU05与SU07在仅F可用的对象上本来相同；有N/Q时一般不同。数值相同不必然是代码未接入。

上述都是固定有解释力的对照，不是权重扫描，也暂不作为原创理论宣称。新类别由完整词表argmax决定；不额外叠加0.01阈值或IR07的投票门控。

## 4. 为什么新增两个“匹配重放”控制？

旧IR06/IR07可能处理了历史F缺失、同视图粗C不可用等对象。如果新融合只在完整来源可用对象上运行，却直接对比旧汇总成绩，就混入了适用范围变化。

因此，先固定共同可用域：父实验选中的已有实例，旧D2/F可用，至少一张父实验成功FULL AnyUp视图，同一组所有FULL视图的粗C均成功，且不存在父协议保护的raw-zero行。

**SU02/SU03只在这个共同域重放旧IR06/IR07决策，域外保留G1。** 它们不能直接填旧论文表中的9.94、10.63；需构造实际预测并复评。另保留原IR06/IR07的完整重建与原始成绩作为谱系与覆盖对照。

共同域由输入身份与可用性确定，不使用GT、类别是否正确或本轮涨跌。场景评分分母仍是整张图，不能只评价共同域。普通C对照也属于这个固定证据重放协议；不能据此声称独立部署FC-only时不需要定义获取策略。

## 6. 计算量与停止边界

共享原26张地图。新建图、分割、N/Q推理、AnyUp Q/K、新视角搜索和参数拟合均为0。父AnyUp成功分数不可用时，先尝试精确的保留副本；仍不可用就记录依赖阻塞，不能为了假装零成本改成另一套输入，也不自动重跑AnyUp。

原粗FC最多补26×16×2=832个FULL区域pooling；distinct图片数通常更少，缺失dense时才编码。832是结构上限，不是预测的实际计算量。所有失败尝试照实计数。

为了避免精度尚未证明就耗费64次冷计时，本轮**端到端冷测次数为0**。仅记录实际补采集成本，以及两轮缓存驻留的CPU决策核耗时。不能用这些毫秒数宣称完整系统很快；父AnyUp和观测建立的成本没有消失。

约十项定向性质测试与两个原有场景的真实接入检查即可；不全仓测试、不重新审核所有旧实验、不做安全/压力测试，不把测试数量当成果。

## 7. 选模规则与科学结论

保留原目标：两队列五项指标均不低于G1；CF18 APall严格高于D2、AP50至少达到D2。使用未取整fraction和1e-10容差。另将CF18 APall超过D2至少0.10pp记录为实质增益标记，不改变通过门槛。

简单控制可以获胜；无人通过则继续保留G1。不能按Replica/CF18分别选方法，不能根据已知正确owner建立保护名单，不能将本轮已曝光选模称为独立泛化。

主要应得到四个答案：保留N/Q是否减少误改；保留旧F是否必要；AnyUp是否优于同视图粗FC；配对差值是否优于直接加新来源。若简单混合足够，先接受简单方案；若仍有纠错和误改同时发生，再定义具有明确训练/验证划分的更新风险研究。**这轮不预先训练一个缺少独立训练证据的判别器。**
