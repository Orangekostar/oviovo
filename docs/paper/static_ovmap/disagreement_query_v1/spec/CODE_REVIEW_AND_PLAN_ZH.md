## 3. 本次审核纠正的两个实验问题

### 两条观测时，“按视角分组再等权平均”是冗余对照
若两条进入同一组，组内平均就是二者均值；若进入两个单元素组，组间平均仍是二者均值。因此它不应作为独立的新实验条件。

本轮替换为 MEAN、可见物理面积 AREA、重叠支持分摊 SUPPORT 三个更新器。SUPPORT 在相同覆盖或完全不相交覆盖下仍可能退化为简单控制，这是需要记录的科学结果，不能强行制造差异。

### 选图不能先偷看所有候选的识别分数
先锁定对象与几何候选集；读取统一起始图；利用起始图的固定子区域定位证据异质性；锁定第二张图；然后才读取选中图。跨策略共享缓存只节约实际计算，不能扩大各策略当时可以访问的信息。

四策略匹配两次完整区域读取，DISAGREEMENT额外使用最多四个起始图子区域pooling／head；只能称完整图像读取预算匹配，不能称总算量相同。

## 4. 算法不再停留在“挑有信息的图”

### 选图：四个具体规则
| 策略 | 第二条观测的选择原则 |
|---|---|
| AREA | 原图可见mask像素最多 |
| COVERAGE | 对象中心球面方向覆盖的新增比例，参考 OVI 的几何标准 |
| VERIFY | 同一物理表面的共同可见比例 × 有限视差，取平方根 |
| DISAGREEMENT | 在 VERIFY 的基础上，优先复核起始图中类别相对响应不同的区域 |

竞争类别来自 G1当前类和D2最强的其他类；不使用GT。起始图按FULL bbox划分最多四个象限区域，固定普通FC给出类别分差。局部分差与FULL分差的绝对偏离用于分配待复核表面权重。它是启发式代理，不是已校准的信息增益；无足够子区域或异质性时精确回退VERIFY。

最终分类仍在完整词表上argmax，不限于这两个竞争类别。

### 更新：只改变新证据的权重
`p_final = 0.75 p0 + 0.25 p_new`，其中 p0 是完整父D2分布。p_new由两条FC FULL证据按MEAN／AREA／SUPPORT形成。历史N/Q/F不反混合、不撤销、不假定可追溯到每一个原始裁剪。

SUPPORT对每个表面单元的面积在观察它的不同记录之间分摊，控制重复表面总质量。它不保证语义正确，也不保证AP不下降；只有完整评价能给出结论。

## 5. 基础诊断不冒充新方法

**物理支持诊断**：区分源行命中、精确坐标聚合、直接深度／BVH验证可见性。精确共点归并不做距离焊接；相邻不同owner不合并。最多4096个确定性面积样本／对象，不改实际地图。

**词表诊断**：在原有分数中保留同一对类别，按固定顺序增加其他原词表类别，对比概率级和分数级融合。不编码新文本，不按GT挑干扰词，不用缩小词表的AP当作涨点。诊断分数融合本轮不自动成为主方法。

完整晋级仍保持：两套数据各五项不低于G1，CF18 APall超过D2、AP50达到D2，使用未舍入fraction与1e-10容差。简单控制可以获胜；无通过者保持G1，部署N0不变。

## 7. 对论文新颖性的定位
OVI-MAP已提出对象中心覆盖选图；ActiveLang是2026-10-07预印本，已研究语义不确定性驱动的主动建图；跨词表VLM校准也有前作。不能仅凭“主动”“不确定性”“概率融合”主张原创。

本轮要争取的是更具体的实证：在相同完整读取预算和固定识别器下，是否能够找到更有辨别力的观测，并利用表面支持减少误改。若普通AREA或均值最好，应该保留简单结论。若最终机制仅通过工程修复才有收益，应区分基线修复和算法贡献。
