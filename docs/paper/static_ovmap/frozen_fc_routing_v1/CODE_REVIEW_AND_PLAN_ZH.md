## 三、四个训练条件

FG1按视图分组、无归属监督；FG2同结构按物理表面分组；FG3加入归属监督但不直接路由；FG4与FG3同监督，让归属直接控制整组采纳。

所有方法冻结FC/phi/text，使用同一原对象、mask、2/4/8前缀与64个局部点。保留相同网络参数形状，但不隐藏FG1/2中未参与监督的membership参数。本轮不训练二维MA、不设教师保持、不加一致性辅助项，不调骨干或词表。

模型输出只能由冻结对象向量与局部FC向量组合。没有自由值映射不代表必然泛化更好；它是为减少混杂变量而作的受控选择，不能把它与上一轮结果直接当作单变量消融。

## 五、关键诊断及其边界

D0使用既有R1/R3和FC结果，解释纠错/误改；不生成白名单。D1用TRAIN/DEV标注作理想局部过滤，只检验当前局部特征是否有去污染机会；不是可部署方法或严格上限，也不决定是否训练四个FG条件。

对FG4增加同采纳质量控制：保留每个query的总alpha，取消表面之间的rho区别。审核发现“同概率质量”不等于“同修正范数”，因此另有同范数诊断，并对零范数无法配对的情况明确标空。两个诊断都不参与选模，不充当新增训练方法或新整图结果。

由“把rho降为0后回到FC”只能证明代码在使用rho，不能证明分类更准。归属预测更准确、污染权重更低、对象识别更好、完整AP更高是四个不同层级，必须分别报告。
