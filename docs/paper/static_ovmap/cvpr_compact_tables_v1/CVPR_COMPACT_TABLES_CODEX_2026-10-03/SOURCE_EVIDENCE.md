Upstream README corrects the paper voxel-size typo to 0.01m; use actual inherited configuration and record a conflict instead of silently changing it.
The three external rows are reported context. Their full scorer identities have not been independently recovered; no cross-provenance numerical superiority claim is certified by this package.
