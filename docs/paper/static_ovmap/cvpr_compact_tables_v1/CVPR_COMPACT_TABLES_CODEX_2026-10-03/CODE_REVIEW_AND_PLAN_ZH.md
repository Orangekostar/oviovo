# 三张实验表的源码审核与执行拆解

日期：2026-10-03。源码锚点：`1a1c4513ecf824c55274a456c40657271d631883`。
本文件是执行规格，不是新增实验结果；未在用户服务器运行建图或模型。

## 1. 最终范围

沿用用户确认的精简方案：Replica-8、ScanNet-CF18；三张主表；八种内部输出。
A0–A5在26条序列上测量，U2与G3仅在Replica上测量，共172条主结果、14个内部池化结果。
26是共享原生地图的总数，不是额外新地图数；已有地图身份一致时直接复用。
最多在一个已有开发场景产生8条接入检查输出，不重新构建开发地图。
24次恢复计时回放仅用于真实冷特征缓存成本，不是24个新方法或新独立试验。

本轮不重新搜索视觉模型、D2权重、温度、文本提示、关联算法或SAM；不增加数据集。
A3固定为“D2＋G1单视图FC恢复”。G3不能看完Replica后替代G1成为主方法。
结果中保留所有简单对照，不因A3未胜出而改名、换行或删数。

## 3. 必须真正开发的能力：G1/G3独立几何观测

G1不是U2的重命名。以最终预测网格构建全场景光线查询，使用每帧真实相机和测量深度，
让没有历史原生请求、但可见且达到固定区域门槛的遗漏owner也有识别机会。

具体固定规则：整场景遮挡；同一三角形三个raw owner一致才分配正owner，混合面仍遮挡；
按原生整像素坐标构造未归一化光线，使t_hit对应相机z深度；用
`abs(z-D)<=max(0.02m,0.02D)`检验深度一致性；至少100可见像素；不填洞不膨胀。
按面积降序、帧号、mask摘要排序，G1取第一张，G3取前三个不同帧。
这些数值是本轮预先规定的设计值，不是从新实验调出的最优参数。

只在原生输出遗漏owner的未归属表面上恢复，不修改已有实例形状，不生成新几何。
语义编码使用整个可见实例mask，导出使用残余支持K，两者不要混成同一mask。
全场景遮挡包含所有owner和未知面，不能只渲染目标，避免把墙后物体投到前景。
实际处理是最终地图回看既有帧的离线语义步骤，不声称实时或因果在线。

A2/A3/A5的新增对象、mask、FC特征、标签完全共享。这才是可解释的2×2。
A4与A3是同视图、不同表示，并非同骨干的pooling消融，不夸大归因。

## 7. 选模、计算量与不必要工作

本轮模型已固定，温度和D2不重新拟合。主方法固定A3，在新主benchmark打分前提交冻结文件。
所有8种条件实测或明确记录技术阻塞；不从Replica里挑最高方法改写成完整方法。
最终报告保留A3相对A0/A1和A4/A5的差值及性能取舍。部署仍不自动替换。

读取旧数据不等于所有新场景已准备好。最多26张新成功主地图只在确实没有可复用地图时发生。
最多一个已有开发场景接入检查，不追加四场开发网格。只运行修改代码直接相关的测试和
一次真实端到端检查，不重跑全仓CROVE、不重验所有历史发布文件、不扩大模型扫描。

计时列改为“特征缓存冷、模型驻留的增量恢复时间”。这与完整冷启动或端到端FPS不同。
实际计时24次，但不是新增24个科学条件；相同RGB帧在单次方法中可共享编码。
计时不读旧dense缓存、视图缓存；模型加载、原生地图成本另外存SI。
